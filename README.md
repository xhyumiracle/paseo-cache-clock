# Cache warmth for Paseo

A prompt-cache countdown beside the message box of Claude agents in [Paseo](https://paseo.sh). Details in [OVERVIEW.md](OVERVIEW.md).

```bash
paseo plugin add git:xhyumiracle/paseo-cache-warmth
```

Or tell your agent: *Install the Paseo plugin github.com/xhyumiracle/paseo-cache-warmth*
